# آپشن هوشمند ایرانیان — نسخه مستقیم گوشی

اپلیکیشن Android/Kotlin با رابط فارسی و تم تیره. برنامه برای دریافت داده مستقیماً از خود گوشی به اینترنت وصل می‌شود و سرور مرکزی ندارد.

## امکانات پیاده‌سازی‌شده
- داشبورد وضعیت اتصال و زمان آخرین تلاش
- درخواست مستقیم زنجیره اختیار TSETMC از مسیر `https://cdn.tsetmc.com/api/Instrument/GetInstrumentOptionMarketWatch/1`
- تلاش برای دریافت پاسخ JSON از `https://cdn.ime.co.ir/` و تشخیص روشنِ حالتی که نشانی پاسخ API داده بازار نیست
- استخراج انعطاف‌پذیر فیلدهای شناخته‌شده قرارداد از JSON؛ عدم نمایش داده فرضی
- به‌روزرسانی خودکار هر ۶۰ ثانیه هنگام بازبودن برنامه و به‌روزرسانی دستی
- فهرست قراردادهای دریافتی با آخرین/خرید/فروش/قیمت اعمال/حجم در صورت وجود در پاسخ
- ماشین‌حساب ساده سود و زیان خریدار اختیار خرید/فروش در سررسید
- گزارش وضعیت منابع و پیام‌های خطای قابل‌فهم

## محدودیت‌های واقعی منابع
- API زنجیره اختیار TSETMC در منابع فنی عمومی مستند شده، اما یک API رسمی با SLA تضمین‌شده نیست و ممکن است تغییر کند یا خارج از ایران دسترسی آن مسدود شود. برنامه در صورت خطا آن را اعلام می‌کند.
- `https://cdn.ime.co.ir/` به‌تنهایی یک قرارداد API عمومی مستندشده برای داده زنده اختیار معامله ارائه نکرده است. این نسخه همان نشانی را بررسی می‌کند؛ اگر پاسخ HTML یا داده غیرقابل‌نگاشت باشد، برنامه به‌صراحت وضعیت «نیازمند API داده» را نشان می‌دهد و قیمت ساختگی تولید نمی‌کند. برای اتصال واقعی IME باید endpoint عمومی مجاز/مستند یا توکن ارائه‌دهنده داده در دسترس باشد.
- این نسخه هیچ قیمتی را به‌عنوان تضمین‌شده/بلادرنگ معرفی نمی‌کند؛ زمان ثبت‌شده در برنامه زمان دریافت پاسخ است مگر آنکه زمان منبع در خود پاسخ قابل تشخیص باشد.
- هیچ سیگنال خریدوفروش خودکار تولید نمی‌شود؛ تا زمان اعتبارسنجی schema و قراردادها، داده ناقص نباید برای معامله استفاده شود.
- ماشین‌حساب هزینه کارمزد، مالیات، تسویه، اندازه‌های خاص قرارداد و قواعد ویژه هر قرارداد ایرانی را اعمال نمی‌کند.
- به‌روزرسانی خودکار هر ۶۰ ثانیه فقط تا وقتی برنامه در پیش‌زمینه باز است انجام می‌شود. اندروید ممکن است شبکه و اجرای پس‌زمینه را محدود کند.

## ساخت APK
نیاز: Android Studio/Android SDK Platform 36، JDK 17 و Gradle 8.13 یا نسخه سازگار.

1. پوشه‌ای را که از ZIP استخراج کرده‌اید مستقیماً در Android Studio باز کنید (پوشه‌ای که `settings.gradle.kts` داخل آن است).
2. Gradle Sync را اجرا کنید.
3. از منوی Build گزینه `Build APK(s)` را انتخاب کنید.
4. فایل debug APK معمولاً در `app/build/outputs/apk/debug/app-debug.apk` ایجاد می‌شود.

### ساخت خودکار
فایل `.github/workflows/android-debug-apk.yml` ساخت APK را در GitHub Actions انجام می‌دهد. محتویات همین پوشه پروژه را در ریشه یک repository خودتان قرار دهید؛ workflow را از بخش Actions اجرا کنید و APK را از بخش Artifacts همان اجرا دریافت کنید.

## حریم خصوصی
این نسخه هیچ داده‌ای به سرور اختصاصی توسعه‌دهنده ارسال نمی‌کند. درخواست‌ها مستقیماً از گوشی به URLهای منبع انجام می‌شوند. برای درخواست‌های HTTP از HTTPS استفاده شده است.
